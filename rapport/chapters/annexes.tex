\chapter{Exemple de contenu généré (extrait)}
\label{annexe:exemples}

Exemple de production pour le patron A3 (aide de déblocage — confusion +
frustration), concept « algorithmes de tri », avec RAG activé :

\begin{quote}
\small\itshape
Ce concept est complexe, c'est normal. [\ldots] Le point de blocage probable
concerne la distinction entre complexités $O(n^2)$ et $O(n \log n)$. [\ldots]
Micro-exercice guidé : triez à la main la liste [5, 3, 1, 4, 2] avec le tri
à bulles en notant chaque permutation.
\end{quote}

Le corpus complet (\texttt{data/corpus\_200.csv}, 220 entrées) inclut pour
chaque ligne l'état détecté, le \texttt{template\_id}, les sources RAG et le
texte intégral.
